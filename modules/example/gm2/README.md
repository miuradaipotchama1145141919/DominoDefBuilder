# GM2 Example

This is a standards-based General MIDI 2 example for DominoDefBuilder. It is not a manufacturer-specific synth definition.

The example uses the GM2 Melody Sound Set banks at MSB 79H and the GM2 rhythm banks at MSB 78H. It includes the required GM2 channel controls, RPNs, GM system messages, master tuning, global reverb and chorus controls, Controller Destination Setting examples, and Key-Based Instrument Controller examples for percussion.

The Domino source also demonstrates shared tables, CCMLink, FolderLink, templates, System Setup, and a separate per-drum-note controller track. These are Domino representation features, not additional GM2 effects.
